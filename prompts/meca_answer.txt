Rules:
1. Answer with a SHORT extractive phrase -- a few words, no full sentence, no

2. Prefer the wording of the quoted source text over the wording of the

3. Answer ONLY what was asked. Do not add a place, a companion or a purpose the

4. For a "when" question, answer with a date written the way the dates in the
   memory are written.
5. A statement marked `intended`, `desired`, `hypothetical` or `asked` is NOT a

   factual question from one of them.
6. A statement marked `superseded` was true and stopped being true. For a
   question with no time in it, answer from the statement that is current. For a
   question that names a time, answer from the statement that was true then.
7. When the memory shows two statements that disagree and neither supersedes the
   other, answer from the one with the later date.
8. When the memory holds nothing that answers the question, answer EXACTLY:
   Not mentioned in the conversation
9. Never guess and never use outside knowledge.
10. The memory below is grouped under headings. "what the memory holds" and
    "linked through" are statements the memory found BOUND to the question's
    own subject. "possibly related" was retrieved by resemblance only -- it
    was never checked against the specific relation asked. Use a
    "possibly related" statement only if it explicitly states the fact asked;
    never as a plausible-sounding guess. When the only thing that fits is
    "possibly related" and it does not explicitly say what was asked, follow
    rule 8.
11. Some questions ask what is LIKELY or PLAUSIBLE rather than what happened
    -- "would X...", "is X likely to...", "what would X's ... be", "could X
    be considered...". The answer to these is normally NOT stated literally
    anywhere: it has to be drawn from what the memory shows about the person
    -- their stated preferences, behaviour, values, circumstances. That is
    the task rule 9 exists alongside, not a violation of it: rule 9 forbids
    inventing a fact with no basis in the memory, not reasoning from facts
    the memory actually states. For a yes/no question of this shape, START
    the answer with "Yes" or "No" (or "Likely yes" / "Likely no" when the
    memory only supports a tendency, not a certainty), then add the few
    words that carry the reason, reusing the memory's own words rather than
    paraphrasing them abstractly. Still follow rule 8 when the memory holds
    NOTHING about the person or topic the question asks about -- inferring
    from nothing is guessing, and rule 9 still forbids that.
